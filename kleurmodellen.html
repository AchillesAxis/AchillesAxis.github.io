Wat zijn kleurmodellen?

Een kleurmodel is een manier om kleuren met getallen te beschrijven. Computers gebruiken dit om kleuren op een scherm weer te geven.

RGB

RGB staat voor rood, groen en blauw. Door deze drie kleuren met elkaar te mengen, kan een scherm veel verschillende kleuren maken. Elke kleur heeft een waarde van 0 tot 255.

RGB(255, 0, 0) is bijvoorbeeld rood. RGB(0, 0, 0) is zwart en RGB(255, 255, 255) is wit.

Hexadecimale kleurcodes

Op websites worden kleuren vaak aangegeven met een code die begint met een #. Bijvoorbeeld: #FF6600. Deze code staat voor een oranje kleur.
